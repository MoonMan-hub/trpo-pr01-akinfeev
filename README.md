# Практическая работа №1 — HTML и базовая CSS-разметка

## Описание

Многораздельная адаптивная страница по дисциплине «Технологии разработки программного обеспечения».

Страница содержит шапку с навигацией, раздел «О курсе», 6 карточек направлений, таблицу с учебными показателями, форму регистрации и подвал.

В качестве визуальных материалов используются изображения из предоставленного dataset.

## Технологии

* **HTML5** — семантическая разметка страницы
* **CSS3** — стилизация, Flexbox, медиазапросы
* **Git** — версионирование проекта

## Структура HTML

```text
body
  header — шапка: логотип и навигация
    nav — меню со ссылками на разделы
  main — основной контент
    section id="about" — «О курсе»: заголовок, описание, изображение
    section id="tracks" — «Направления»: 6 карточек
      article — карточка: категория, тема, описание, значение
    section id="schedule" — «Расписание»: таблица
    section id="signup" — «Регистрация»: форма
  footer — подвал
```

### Использованная семантика

В проекте используются следующие семантические элементы:

* `header`
* `nav`
* `main`
* `section`
* `article`
* `figure`
* `footer`

### Иерархия заголовков

На странице соблюдается последовательность заголовков:

```text
h1

 │    ├── h3
 │    └── h3

```

Пропусков уровней заголовков нет.

## CSS-приёмы

В проекте используются следующие CSS-возможности:

* `box-sizing: border-box` для удобного расчёта размеров элементов;
* **Flexbox** для шапки, навигации, главного блока, карточек и формы;
* `flex-wrap` для переноса элементов на новую строку;
* `gap` для расстояний между элементами;
* `max-width` для ограничения ширины основного содержимого;
* `border-radius` для оформления блоков;
* `:hover` для интерактивных состояний;
* `:focus` для отображения фокуса при навигации с клавиатуры;
* медиазапрос `@media (max-width: 720px)` для мобильной версии;
* `rem` не используется — размеры шрифтов и отступов заданы преимущественно в `px`.

### Адаптивность

При ширине экрана до `720px`:

* шапка перестраивается в столбик;
* навигация переносится;
* размер заголовков уменьшается;
* отступы основных секций становятся меньше;
* элементы главного блока могут переноситься благодаря `flex-wrap`.

## Доступность

Для основных элементов формы используются:

* связанные `label` и `input`;
* обязательные поля через `required`;
* ограничения `minlength`, `maxlength`, `min` и `max`;
* `type="email"` для проверки email;
* видимое состояние `focus` для ссылок, полей формы и кнопки;
* `alt` у изображений;
* `aria-label` для навигации и ссылки с логотипом.

## Локальный запуск

1. Клонировать репозиторий:

```bash
git clone https://gitverse.ru/DCPNmlin/trpo-pr01-student
```

2. Перейти в папку проекта:

```bash
cd trpo-pr01-student
```

3. Открыть файл `index.html` в браузере.

Также можно использовать **Live Server** в VS Code.

## Проверка

Для проверки страницы можно выполнить следующие действия:

* открыть `index.html` и проверить отображение всех разделов;
* нажать на пункты навигации и проверить переход к соответствующим секциям;
* проверить наличие 6 карточек направлений;
* проверить таблицу и её заголовки;
* проверить обязательные поля формы;
* нажать `Tab` и проверить видимость фокуса;
* открыть DevTools (`F12`) и проверить отсутствие ошибок в Console;
* уменьшить ширину окна примерно до `375px` и проверить адаптивность страницы;
* проверить отображение изображений логотипа и обложки.
